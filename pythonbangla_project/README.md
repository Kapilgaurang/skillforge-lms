# SkillForge LMS 🚀

An AI-powered Learning Management System built using Django.

## Features

- User Authentication
- AI Courses
- Quiz System
- Auto Score Saving
- Leaderboard
- AI Chatbot
- Dynamic Certificates
- Dark Mode
- User Profiles
- Responsive Design

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite
